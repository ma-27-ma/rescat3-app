# Rescat3 App

UX/UI design project for a mobile app promoting sustainable habits through the 3Rs: reduce, reuse and recycle.

## About the project

Rescat3 App is a mobile application concept designed to encourage sustainable habits based on the principles of **reduce, reuse and recycle**.

The project focuses on creating a simple and engaging mobile experience that makes sustainability-related information and actions easy to understand and use.

## Prototype

The project includes an interactive mobile prototype designed in Figma.

**Tools:** Figma, UX/UI Design, Mobile Design

## Project goals

* Design an intuitive mobile user experience.
* Make sustainability information easy to understand.
* Encourage users to adopt more sustainable habits.
* Create a clear and consistent mobile interface.
